# الاعتمادات داخل المشروع

**الحالة:** فكرة مؤجّلة للنقاش لحين اكتمال التصور الرئيسي واتخاذ قرار مستقل بشأن التنفيذ.

## الفكرة

بند عام للاعتمادات داخل كل مشروع يخدم المقاول الرئيسي ومقاولي الباطن ومالك المشروع عبر جميع التخصصات. يستطيع المقاول الرئيسي مثلًا اعتماد عينات السيراميك أو الرخام أو الحجر التي يرفعها مقاول الباطن. ويُقترح منح مالك المشروع حسابًا خارجيًا محدودًا بالاطلاع على الطلبات الموجهة إليه ومرفقاتها واتخاذ قرار بشأنها. الهدف تقليل زمن انتظار الموافقة قبل الشراء أو التنفيذ وتوثيق النسخة التي اعتُمدت.

## أسئلة للجلسة القادمة

- كيف تُحدَّد جهة الاعتماد لكل نوع من الطلبات في المشروع؟ ومتى يُشترط اعتماد المالك أو الاستشاري؟
- ما أنواع الاعتمادات والقرارات المطلوبة؟ وكيف تُعامل العينة البديلة أو النسخة المعدّلة؟
- ما حدود اطلاع كل طرف، وكيف يتابع المقاول الرئيسي الطلبات المعلّقة؟

يُستأنف بحث النطاق والصلاحيات ومسار الموافقة عند استكمال التصور مع صاحب المشروع. التنفيذ والجدولة مؤجّلان.
